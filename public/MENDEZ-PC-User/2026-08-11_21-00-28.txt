  # Build the GuardianSafe (Before Finishing 7c)
  
  Per the design doc's original guardian model: a fast, 1-of-3 Safe
  separate from the 2-of-2 AdminSafe, able to pause NexaiCore instantly
  without needing the slower admin quorum. This doesn't exist yet —
  building it now, before completing 7c's role revocation, so there's
  no gap where nobody can pause.
  
  ## Structure
  
  **Flat 1-of-3 Safe** (not nested — this is deliberately simpler than
  the AdminSafe, since speed matters more than the "one mandatory
  signer" structure here):
  
  ```
  Owner 1: Mendez        0xd505367868A87fA774c47A28ECb64a5962747E98
  Owner 2: Dmitry backup 1  0xD4DE6d75580ea8d76a4Db583b17FcCcc5882571D
  Owner 3: Dmitry backup 2  0xF99C1aA669A131955a2dd9cc9814013d4160135e
  Threshold: 1
  ```
  
  Same three real signer addresses already used for the nested
  AdminSafe — any one of the three can trigger pause alone.
  
  ## Requirements
  
  - New script, e.g. `DeployGuardianSafe.s.sol` — same
    `createProxyWithNonce` pattern already proven in
    `DeployNestedAdminSafe.s.sol`, reusing the same confirmed `SafeL2`
    singleton, factory, and fallback handler addresses
  - After deploying, grant `GUARDIAN_ROLE` on the new NexaiCore
    (`0x7A7a78F5A28830025023EaBC8ad9cddb7c3d579c`) to the new
    GuardianSafe
  - **First check whether the deployer EOA currently holds
    `GUARDIAN_ROLE`** — if it does, this needs the same grant-verify-
    revoke discipline as every other migration: grant to GuardianSafe
    first, verify, only then revoke from the EOA
  - Do NOT touch `ADMIN_ROLE`/`DEFAULT_ADMIN_ROLE` here — that's Step
    7c's job, separate and still pending
  
  ## Verification
  
  ```
  cast call 0xEeGuardianSafeAddress "getOwners()(address[])" --rpc-url $BASE_SEPOLIA_RPC_URL
  cast call 0xEeGuardianSafeAddress "getThreshold()(uint256)" --rpc-url $BASE_SEPOLIA_RPC_URL
  cast call 0x7A7a78F5A28830025023EaBC8ad9cddb7c3d579c "hasRole(bytes32,address)(bool)" $(cast keccak "GUARDIAN_ROLE") <GuardianSafeAddress> --rpc-url $BASE_SEPOLIA_RPC_URL
  ```
  
  Confirm: 3 owners exactly matching the addresses above, threshold 1,
  and GuardianSafe genuinely holds `GUARDIAN_ROLE`.

  - Testnet only, no mainnet
  - Standard process: run `forge build && forge test` first, paste the

  - Once this is done and verified, we return to finishing Step 7c
    (granting timelock ADMIN_ROLE/DEFAULT_ADMIN_ROLE, revoking from the
    EOA) with the guardian pause already safely in place

   * migration script in this repo even though the revoke branch is expected to be a
   * no-op here.
