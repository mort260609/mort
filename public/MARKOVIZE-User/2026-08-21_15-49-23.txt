  # EcomNerve — Profit Lab, Ad Spy, Store Audit Upgrade & Creative Analyzer
  
  Upgrade the existing EcomNerve application with four features. Every number shown anywhere in these features must come from either real user input, a real fetched data source, or an explicitly-labeled AI judgment — nothing fabricated or presented as live data when it isn't. Do NOT remove or break Auth, Credits, Dashboard, Store Analyzer, Ad Metrics, Trending Products, Competitor Finder, or Store Tracker.
  
  ---
  
  # Part 1 — Profit Lab
  
  Merge the existing Profit Calculator and Break-even Calculator into a single, more powerful page at `/profit-lab`. Keep both existing routes redirecting here so nothing breaks.
  
  **Inputs:**
  - Product cost
  - Selling price
  - Shipping cost
  - Ad cost per unit (or total ad spend + estimated units, user's choice via a toggle)
  - Currency selector (reuse existing component)
  
  **Calculate, all pure functions in a shared `lib/profit-calculations.ts`, no external data needed:**
  - Gross profit = Selling price − Product cost
  - Net profit = Selling price − Product cost − Shipping cost − Ad cost
  - Profit margin = (Net profit / Selling price) × 100
  - Break-even CPA = Selling price − Product cost − Shipping cost
  - Maximum sustainable ad spend (per unit) = Break-even CPA
  - Required ROAS = Selling price / (Product cost + Shipping cost + desired ad cost) — show this as a small formula-driven table across a few ad-cost scenarios, not a single number, since required ROAS changes with ad spend
  - Recommended selling price for a target margin (e.g. let the user pick a target margin % and back-solve for selling price)
  
  Same edge-case handling standard as Ad Metrics Calculator: no NaN/Infinity, "--" for undefined results, inline validation for negative/zero inputs.
  
  Visual style matches Ad Metrics Calculator exactly — this is a sibling tool, not a redesign. Reuse MetricCard, StatusBadge, and chart components already built.
  
  Update sidebar: remove "Profit Calculator" and "Break-even Calculator" as separate items, replace with a single **Profit Lab** entry under a **PROFIT** section.

  # Part 2 — Ad Spy (real data via Meta Ad Library)
  
  New route `/ad-spy`, under a new **ANALYTICS** sidebar section.
  
  Uses Meta's public Ad Library API (no auth required for basic search, free) via a new edge function `search-ad-library`.
  
  **Search UI:**
  - Keyword or advertiser/domain search input
  - Country selector (Ad Library requires a country parameter)
  - Ad type filter if supported (e.g. all ads / issue-political-and-social)
  
  **Results:** real ad data returned by the API — advertiser name, ad creative (Meta's Ad Library provides links/previews — link out to the actual ad on Meta's Ad Library rather than trying to re-host or reproduce the creative), number of active ads found, platforms it's running on (Facebook/Instagram), start date if provided.
