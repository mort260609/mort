  Trading Bot Update Guide
  Important: Always backup your current configuration and settings before performing any updates.
  1. Pre-Update Checklist
  Backup settings.json file
  Backup .env file (if using live trading)
  Stop the currently running bot instance
  Check current version in Cargo.toml
  Review recent changes in Git history if applicable
  2. Updating Rust Dependencies
  Step 1: Update Cargo.toml
  Edit Cargo.toml to update dependency versions:
  
  [dependencies]
  reqwest = { version = "0.12", features = ["json", "rustls-tls"], default-features = false }
  tokio = { version = "1.35", features = ["full"] }
  Step 2: Update dependencies
  Run the following command to update dependencies:
  
  cargo update
  3. Rebuilding the Bot
  Step 1: Clean previous build
  cargo clean
  Step 2: Build release version
