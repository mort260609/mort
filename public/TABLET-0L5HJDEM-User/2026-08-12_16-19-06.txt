  A. The AI Software Supply Chain
  An agent’s supply chain spans four artifact classes that
  differ in form but share a trust deficit. Skills bundle natural
  language instructions, scripts, and tool bindings, and are loaded
  directly into an agent’s reasoning. MCP servers expose tools
  to an agent through a standard protocol, sitting between the
  agent and external systems. Packages are libraries drawn from
  registries such as npm and PyPI, executed at install and import
  time. Repositories are the source trees that agents and their
  dependencies are built from. Each is composed and executed
  with little or no review, and each can carry malice in a different
  place.
  B. Why Static and Language Model Analysis Fall Short
  Two dominant approaches fail for distinct reasons. Static
  inspection parses an artifact without running it, so it never observes the behavior that defines maliciousness, and obfuscation
  readily defeats it because the damaging action is only assembled
  at runtime. A scanner that delegates judgment to a language
  model inherits the model’s own weakness: the artifact’s text is
  consumed as reasoning context, so a crafted description can
  prompt inject the very scanner meant to catch it, and the output
  is prose a human reads rather than a verdict a runtime can
  enforce. Recent behavioral detectors that execute artifacts and
  compare observed behavior against declared intent substantially
  outperform static and pattern based tools, by margins reported
  in the tens of F1 points for malicious MCP server detection [1],
  1
  which is direct evidence that grounding analysis in execution is
  the stronger basis for a verdict. Phylax builds on that evidence
  and makes the resulting verdict cryptographically verifiable
  and economically incentivised.
