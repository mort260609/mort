  📦 Super HPI – Enterprise Inventory, Stock Dispatch & Invoice Management System
  Project Overview
  Super HPI Inventory Control is a full-stack, enterprise-grade Web Application designed for auto-parts manufacturers, distributors, and wholesalers. The system automates end-to-end inventory tracking, stock movements, client shop ledgers, sales invoicing, walk-in customer payment collection, and financial analytics.
  Built with a modern tech stack, this application handles high-volume inventory operations with real-time shop ledger updates, stock auto-deduction upon dispatch, custom PDF invoice generation, and financial auditing.
  🌟 Key Features & Capabilities
  Stock Out (Dispatch Management):
  Create multi-item dispatches with automatic stock level validation and real-time ledger deduction.
  Dual customer workflows: Registered B2B Shops (ledger balance tracking) & Walk-in Retail Customers (immediate payment collection with quick payment presets).
  Invoice Archive & PDF Billing System:
  Automated sequential invoice creation with transport charges, tax, discounts, and itemized totals.
  Built-in thermal/A4 print-ready view & quick PDF export.
  Quick payment collection modal for updating partial/full invoice balances.
  Shop Directory & Credit Ledger:
  Real-time outstanding balance calculation for every wholesale customer shop.
  Automated ledger updating whenever a dispatch or payment occurs.
  SKU & Product Inventory Catalog:
  Comprehensive SKU tracking with minimum alert levels, unit costs, and stock-in history.
  Purchases & Supplier Management:
  Track inbound raw materials and products from suppliers with stock addition.
  Daily Expenses & Financial Reports:
  Operating expense log, expense categories, profit & loss summary, and visual reports with charts.
  Security & Data Integrity:
  JWT-based authentication, role-based access control, and full database backup/resiliency.
  🛠️ Technologies Used
  Frontend Framework: Next.js 15 (App Router), React 19, TypeScript
  Styling & UI Components: Tailwind CSS, Tailwind Animate, Lucide React Icons, Framer Motion
  Backend Architecture: Next.js Server API Routes (/api/*), Node.js
  Authentication: Custom JWT (JSON Web Tokens) with cookie session management
  Data Visualization: Recharts / D3.js (Financial analytics and reports)
  Document Generation: Embedded CSS @media print engine for instant A4/Thermal PDF invoice printing
  State Management: Zustand / React Custom Hooks with optimistic state updates
