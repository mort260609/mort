  We are building a portfolio of AI-enabled partner-operations workflows for a go-to-market organization. The immediate work includes evaluating and implementing account-mapping workflows using Crossbeam MCP, designing a Claude-based deal-management assistant or skill, and improving manual partner eligibility and onboarding processes.
  
  This is not a website-design role, a front-end development role, or a generic prompt-engineering engagement. We need a senior, hands-on builder who can discover the current process, define the solution architecture, integrate business systems safely, implement and test the workflow, and leave the internal team with durable documentation and a supportable operating model.
  
  The work will be organized as a sequential project queue. The current planning target is approximately four projects for this contractor, delivered one at a time rather than simultaneously. The exact sequence will be finalized during discovery.
  Initial project themes
  Determine where Crossbeam MCP adds practical value to partner account mapping, prioritization, and deal workflows.
  Design or implement a Claude-based deal-management assistant or reusable skill that surfaces the right partner context at the right point in the deal process.
  Map and improve partner eligibility and onboarding workflows that currently depend on manual coordination.
  Identify additional high-value partner workflows, rank them by impact and implementation risk, and convert the approved items into a sequenced delivery plan.

  Define the first project's scope, acceptance criteria, dependencies, risks, and implementation plan before build begins.
  Evaluate the available Crossbeam MCP capabilities against the actual account-mapping and deal-management use cases.
  Design and implement AI-assisted workflows using Claude, MCP, APIs, webhooks, and the organization's existing business systems where appropriate.
  Define how account and partner context is retrieved, filtered, presented, acted on, and written back without exposing unauthorized data.
  Build appropriate human review, approval, escalation, and fallback paths for actions that should not be fully autonomous.

  Produce durable documentation: solution architecture, workflow diagrams, integration maps, decision rules, test plan, runbook, known limitations, and knowledge-transfer materials.

  Hands-on API integration experience, including REST APIs, JSON, webhooks, authentication, pagination, rate limits, retries, timeouts, and failure handling.
  Experience implementing Claude, another production LLM, or an AI agent inside an operational workflow rather than only building a standalone chatbot.
  Ability to translate ambiguous manual processes into explicit rules, states, exceptions, ownership, and measurable acceptance criteria.
  Experience working with CRM, sales operations, Revenue Operations, deal-desk, partner operations, or comparable go-to-market workflows.
  Practical understanding of data permissions, least-privilege access, auditability, and human approval boundaries.
  Ability to lead discovery with nontechnical stakeholders and work directly with internal technical owners.

  Model Context Protocol implementation experience.
  Experience building Claude skills, tools, or agent workflows.
  CRM automation and data synchronization experience.
  Evaluation frameworks for measuring workflow accuracy, adoption, time saved, exception rate, and business impact.

  The workflow is tested, observable, documented, and maintainable by the internal team.
