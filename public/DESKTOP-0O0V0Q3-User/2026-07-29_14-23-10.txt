  What is on a Raspberry Pi?
  
  A typical Raspberry Pi has:
  
  🧠 CPU (Processor) – the "brain" of the computer.
  💾 RAM – temporary memory.
  🔌 USB ports – for a keyboard, mouse, etc.
  🖥️ HDMI port – to connect a monitor.
  🌐 Ethernet/Wi-Fi – for networking.
  📷 GPIO pins – special pins for connecting sensors, LEDs, motors, and other electronics.
  
  Unlike a laptop, it doesn't usually come with a screen, keyboard, or storage. You typically insert a microSD card that contains the operating system (such as Raspberry Pi OS), then connect it to a monitor, keyboard, and mouse.
  
  Why do people use Raspberry Pi?
  
  It's popular for learning programming and building projects such as:
  
  Home automation
  Robotics
  Weather stations
  Security cameras
  Web servers
  IoT (Internet of Things) devices
  
  Since Python is preinstalled or easy to install on Raspberry Pi OS, it's one of the most common languages used on the device.
  
  So, when you read:
  
  Python works on Raspberry Pi
  
  it means:
  
  You can install and run Python programs on a Raspberry Pi computer, just as you would on a Windows PC or a Mac.
  [Clipboard]
  It doesn't need to convert the entire program into machine code before running it.
