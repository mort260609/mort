  Una estrategia no es más que un conjunto de reglas claras que sigues a rajatabla. No operas por corazonada o intuición, sino cuando se cumplen tus requisitos.
  
  Vamos a ver la estrategia más clásica y efectiva para principiantes: Entrada en Re-testeo de Soporte (o Estrategia de Continuación).
  
  Paso a paso de la Estrategia:
  Identificar la Zona Clave: Buscas un nivel que haya funcionado como Resistencia (techo) en el pasado.
  
  Esperar la Ruptura: Una vela rompe ese techo con fuerza hacia arriba.
  
  Paciencia para el Retorno (El Re-testeo): No compras arriba del todo cuando el precio está volando (eso es un error común llamado FOMO o miedo a quedarte fuera). Esperas a que el precio vuelva a bajar a "testear" ese viejo techo, que ahora debería actuar como Soporte (piso).
  
  Confirmación con Velas: Esperas a que aparezca una vela verde en ese piso que indique que los compradores están defendiendo el nivel.
  
  Ejecución y Gestión:
  
  Punto de Entrada: Donde abre la siguiente vela tras la confirmación.
  
  Stop Loss (SL): Un poco por debajo del nuevo piso (por si el piso no aguanta).
  
  Take Profit (TP): Buscando al menos el doble del riesgo (Ratio 1:2).
  
  Plaintext
                                             🚀 Take Profit ($69,000)
                                              /
                                             /  <- Zona de Ganancia (+ $2,000)
         Ruptura                            /
         /-----\              Entrada      /
        /       \                |        /
  -----/--------- \--------------*-------/------ $65,000 (Vieja Resistencia / Nuevo Soporte)
      /           \             /
     /             \___________/ <- Zona de Riesgo (- $1,000)
    /                             🛑 Stop Loss ($64,000)

  strategy("Estrategia Breakout & Retest + Tabla", overlay=true, initial_capital=1000, default_qty_type=strategy.percent_of_equity, default_qty_value=10)
  
  // --- CONFIGURACIÓN DE PARÁMETROS ---
  g_strat   = "Configuración de Estrategia"
  pivotLen  = input.int(10, "Sensibilidad de Niveles (Periodo Pivot)", minval=2, group=g_strat)
  rrRatio   = input.float(2.0, "Ratio Riesgo/Beneficio (TP)", minval=1.0, step=0.1, group=g_strat)
  slMargin  = input.float(0.5, "Margen extra para Stop Loss (%)", minval=0.1, step=0.1, group=g_strat) / 100
  
  // --- DETECCIÓN DE ZONAS (Soportes y Resistencias) ---
  ph = ta.pivothigh(high, pivotLen, pivotLen)
  
  var float resLevel = na
  if not na(ph)
      resLevel := ph
  
  // --- LÓGICA DE LA ESTRATEGIA (Break & Retest) ---
  var bool estaRoto = false
  var float resistenciaRota = na
  
  // 1. Ruptura: El precio de cierre supera la resistencia
  if not na(resLevel) and ta.crossover(close, resLevel)
      estaRoto := true
      resistenciaRota := resLevel
  
  // 2. Re-testeo y Confirmación: El precio toca la zona y reacciona al alza (vela verde)
  reTest   = estaRoto and low <= resistenciaRota and close >= resistenciaRota
  confirmacion = reTest and close > open // Vela verde en la zona
  
  // --- CÁLCULO DE SL Y TP ---
  var float slPrice = na
  var float tpPrice = na
  
  if confirmacion and strategy.position_size == 0
      // SL justo debajo del mínimo de la vela de confirmación o de la zona de soporte
      slCalculado = math.min(low, resistenciaRota) * (1 - slMargin)
      distanciaRiesgo = close - slCalculado
      
      if distanciaRiesgo > 0
          slPrice := slCalculado
          tpPrice := close + (distanciaRiesgo * rrRatio)
          
          // Ejecución de la orden
          strategy.entry("Long Retest", strategy.long)
          strategy.exit("Salida Long", "Long Retest", stop=slPrice, limit=tpPrice)
          
          // Resetear estado tras la entrada
          estaRoto := false
  
  // Cancelar estado si el precio cae demasiado sin confirmar
  if estaRoto and close < resistenciaRota * 0.97
      estaRoto := false
